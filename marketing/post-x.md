# Codex Review Setup

I turned my Python project into a self-reviewing repo: automated Codex reviews, research pipeline, Telegram alerts, and GitHub Actions CI — all running on systemd timers.

No more manual reviews. No more “did I miss anything?” at 2am.

**What I built:**
- 🔁 Scheduled Codex reviews Mon/Wed/Thu
- 📰 Automated research on any topic
- 🔔 Telegram alerts on issues
- ✅ CI with pytest, coverage, mypy, ruff, secret scan
- 📦 Reusable starter template

**Stack:** Codex CLI, pytest, systemd, GitHub Actions

Use case: indie devs, small teams, solo maintainers who want automated code quality without the overhead.

If you want the template: github.com/AlexKrikovluk/codex-review-starter
